另以透明 PNG 的有/无单个 shadow 对照检查 36 组控件状态，确认所测浏览器画面确实绘制外阴影。这是内部光学回退修复与浏览器阴影排查，不能作为用户所述原生外阴影消失已解决的证明。依据、像素报告、原始对照及限制见 [验证记录](../artifacts/material-redesign/qa/shadow-continuity-audit-20260927/VERIFICATION.md)。

## 中性云母与毛玻璃区分、描边减弱（2026-09-27）

按用户要求全程离屏。云母提高底色覆盖与背景扩散，采用哑光浅灰和更低噪声；毛玻璃保留更多背景颜色，最低 Gaussian 标准差从 2 px 提至 18 px。三材质的普通组件描边从 .54–.22 降为 .14–.10，并移除第二圈 inset 线；键盘焦点与选中提示保留。设置标题的颜色渐变也已移除，避免深浅模式切换时文字和底色不同步。

11 项前端单元、8 项相关 Rust 检查通过；120 个独立 UI 用例经两处模拟就绪时序修正后通过，最终云母色调调整另复查其中 20 项。前端及主程序/测试程序 debug 构建通过。三轮各 24 张虚构背景离屏截图、失败复现、源码散列和准确计数见 [验证记录](../artifacts/material-redesign/qa/material-separation-20260927/VERIFICATION.md)。中性云母不等于 Microsoft 原生壁纸 Mica；离屏结果也不证明真实移动/焦点的合成稳定性或 iOS 完全一致。

## 修复范围

- 原生窗口通过 Tauri/Tao 的 preferred theme 锁定手动明暗模式，并同步 DWM 材质。前端命令使用正确的 camelCase 参数，按顺序提交，避免快速切换时旧请求覆盖新选择。启动时先读取已缓存的颜色模式，SQLite 设置加载后再校准。
- 热键、关闭按钮、失焦隐藏、粘贴后隐藏、边缘停靠隐藏统一通知前端重置临时页面状态。仅失去焦点而未隐藏的固定窗口继续保留当前页面。历史数据、标签及用户偏好不在重置范围内。
- 剪贴板采集去重时保留原记录的标签、敏感标记、置顶信息和使用次数。更新记录与标签关联在同一事务内完成，随后才执行容量清理。数据库查询失败时停止本次分发，避免展示未保存的记录。
- 标签页小于等于 620px 时使用顶部标签栏，更宽时使用侧栏。标签切换和刷新使用请求序号防止过期响应覆盖当前内容；读取失败保留已有条目并显示错误。编辑及批量粘贴按 ID 读取完整内容，避免使用列表截断预览。
- 标签页仍保留原有的删除语义：删除标签会删除该标签下的所有条目，操作前有明确确认；单条删除和粘贴是独立按钮。
- 重做云母和毛玻璃材质，加入液态玻璃及单一透明度滑块。适配明暗模式、Windows 10 实色降级、减少透明度与减少动态效果。

首次运行浏览器测试需要 `npx playwright install chromium`。也可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定已有的 Chromium。测试页面仅存在于 tests/ui/harness.html，不会进入 Vite 正式构建入口。所有 Tauri 调用都被拦截，只使用虚构数据，不访问真实剪贴板、文件或数据库。

## 材质与启动性能修正（2026-09-14）

旧版在透明度端点关闭原生背景，导致 99%→100% / 0%→1% 切换渲染路径；整窗模糊、SVG 位移与文字阴影又放大了轮廓光和重影。本次删除这些效果，三种材质在整个滑块范围内保持同一种原生背景，连续改变底色强度。内容、控件与顶栏分别保留可读底色。液态玻璃依然只有一个透明度滑块；缓存值在设置加载前生效，旧独立模糊参数不再参与渲染。

- 新增的五条原始回归均在修改前失败、修改后通过，覆盖三种材质的端点原生切换、启动时程序扫描/隐藏 WebView 预热、正文与整窗滤镜。
- 浏览器对液态玻璃、云母、毛玻璃的浅色/深色、七档滑块位置和黑/灰/白背景检查标题、正文、元信息、筛选文字的合成对比度（至少 4.5:1）。另覆盖樱花主题连续性、单滑块持久化、设置延迟加载、减少透明度/动态效果和四角填充。
- 保留筛选胶囊移动、轻量按压反馈和短距离页面过渡，移除全局指针光效、SVG 噪声和隐藏预览窗口预热。设置、标签、表情及辅助窗口按需加载。默认程序只在打开相关设置时扫描，成功后在当前会话缓存。
- 原生 Shell 程序/文件图标查询和默认应用查询转移到后台工作线程，在线程内配对初始化/释放 COM。新增测试核对执行线程以及系统程序图标 PNG、缓存结果；不启动该程序。
- 保留 Windows 11 DWM 单层圆角裁切以及 Windows 10 实色降级。Windows 快捷键继续使用 Ctrl / Alt / Shift / Win 键名，并通过 250px / 352px 布局与录制回归。

## 验证边界

浏览器使用虚构数据并拦截全部 Tauri 调用，不能证明真实 DWM 桌面合成、实际粘贴目标或开机自启动效果。前端性能对照使用生产构建、每组五次新浏览器上下文和相同 4 倍 CPU 限速；不包含原生进程启动、数据库读取与桌面合成时间。

本轮未执行真实 Windows 窗口交互或重启验证，未操作真实剪贴板或数据库。实际窗口需在正常用户会话核对系统深色/应用浅色、0/1/99/100 端点及启动初期交互。
